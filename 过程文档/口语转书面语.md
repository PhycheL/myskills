### 口语转书面语（文本整理）

这是核心步骤。对第一步生成的 md 文件进行口语化表达的清理，转化为通顺的书面语。

**处理原则——忠于原文：**
这一步只做语言层面的清洁工作，不改变内容结构、不增删观点、不重新组织段落。把它想象成一个专业的速记员在做"逐字稿→整理稿"的转换：听懂说话人的意思，但只清除语言噪音，不添加自己的理解。

**需要清理的内容：**

1. **语气词和填充词**
   删除不承载信息的语气词：是吧、对吧、是不是、好、好吧、啊、嗯、呢、吧、哈、嘿、哎、唉、那个、这个、就是说、怎么说呢、你知道吗……

   注意：当这些词承载实际语义时要保留。比如"好，我们开始"中的"好"是转折信号，应保留。

2. **口语重复**
   将连续重复的词语合并为一个：
   - "一个一个一个一个" → "一个"
   - "那那那那" → "那"
   - "去去去" → "去"
   - "和和和" → "和"
   - 以及结巴式的重复如"英英国那些英英国那些" → "英国那些"

3. **时间戳**
   删除所有录音时间标记，如 `00:07`、`01:38`、`12:30` 等格式的时间戳。

4. **冗余表达精简**
   将散乱的口语表述整理为通顺的书面语：
   - 保持说话人的原意和逻辑顺序
   - 不要合并段落、不要调整段落顺序
   - 不要增加总结性文字或过渡句
   - 只让句子读起来更流畅

5. **语音识别纠正**
   这份文档是录音经过语音识别（ASR）得到的，语音识别引擎会把一些词听错——最常见的是同音字/近音字替换（如人名、专业术语、地名等）。在整理过程中，需要根据上下文语义识别出这些识别错误并纠正。

   **判断方法：**
   - 某个词放在句中语义不通或很突兀，但换成一个发音相近的词就合理了——这大概率是语音识别错误
   - 尤其关注人名、机构名、专业术语、成语、固定搭配，这些是语音识别最容易出错的地方
   - 同一个名称在文中出现多次但写法不一致，通常说明部分出现是识别错误

   **纠正原则：**
   - 只纠正有较高把握的错误，拿不准的不改（宁可漏掉也不要改错）
   - 纠正后要确保在上下文中语义通顺

   **展示纠正结果：**
   完成第二步后，在告知用户产出文件路径的同时，列出本步所做的语音识别纠正。格式如下：

   ```
   主要语音识别纠正：
   
   - "东玄老师" → "东平老师"
   - "单位已经在场" → "单位遗产在场"
   ```

   如果没有发现需要纠正的语音识别错误，也要说明"未发现明显的语音识别错误"。
