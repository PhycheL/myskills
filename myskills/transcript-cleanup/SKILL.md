# 录音转录文档整理

将录音转录的 docx 文件通过三步流水线处理成整洁、有结构的 markdown 文档。三步的结果文件都会保留，以文件名区分。

## 处理流程

整个流程分为三步，每一步都生成独立的 md 文件，便于用户回溯和比较。

### 第一步：docx 转 md（原文提取）

将 docx 转录文件转换为 markdown 格式，保留原始内容。

**操作方式：**
使用 pandoc 将 docx 转换为 md：

```bash
pandoc "输入文件.docx" -o "输出文件_原文.md" --wrap=none
```

**文件命名规则：**
- 输入：`XXX.docx`（原始录音转录文件）
- 输出：`XXX_原文.md`（如果文件名已含"原文"则直接用 `.md` 后缀）

### 第二步：口语转书面语（文本整理）

这是核心步骤。对第一步生成的 md 文件进行口语化表达的清理，转化为通顺的书面语。

**处理原则——忠于原文：**
这一步只做语言层面的清洁工作，不改变内容结构、不增删观点、不重新组织段落。把它想象成一个专业的速记员在做"逐字稿→整理稿"的转换：听懂说话人的意思，但只清除语言噪音，不添加自己的理解。

**需要清理的内容：**

1. **语气词和填充词**
   删除不承载信息的语气词：是吧、对吧、是不是、好、好吧、啊、嗯、呢、吧、哈、嘿、哎、唉、那个、这个、就是说、怎么说呢、你知道吗……

   注意：当这些词承载实际语义时要保留。比如"好，我们开始"中的"好"是转折信号，应保留。

2. **口语重复**
   将连续重复的词语合并为一个：
   - "一个一个一个一个" → "一个"
   - "那那那那" → "那"
   - "去去去" → "去"
   - "和和和" → "和"
   - 以及结巴式的重复如"英英国那些英英国那些" → "英国那些"

3. **时间戳**
   删除所有录音时间标记，如 `00:07`、`01:38`、`12:30` 等格式的时间戳。

4. **冗余表达精简**
   将散乱的口语表述整理为通顺的书面语：
   - 保持说话人的原意和逻辑顺序
   - 不要合并段落、不要调整段落顺序
   - 不要增加总结性文字或过渡句
   - 只让句子读起来更流畅

**文件命名规则：**
- 输入：`XXX_原文.md`
- 输出：`XXX_整理.md`

### 第三步：简单分类整理

对第二步的整理稿进行轻量级的结构化处理。注意是"简单整理"而非深度重构。

**处理内容：**
1. **添加大标题**：根据全文内容总结一个概括性的题目作为一级标题
2. **一级分类**：根据话题的自然转换，将内容划分为几个大板块，每个板块加一个二级标题
3. 不做更深层次的结构调整（不加三级标题、不重排段落内容、不添加总结）

**文件命名规则：**
- 输入：`XXX_整理.md`
- 输出：`XXX_分类.md`

## 执行要点

- 三个步骤按顺序执行，每步完成后告知用户产出文件的路径
- 所有中间文件都保留，不删除
- 如果用户只提供了某一步的输入文件（比如已有 md 文件），从对应的步骤开始即可
- 如果 pandoc 未安装，提示用户安装：`brew install pandoc`（macOS）
