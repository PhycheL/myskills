# 关联原文引用

当天报告的 `references` 非空时使用。原始版保留“关联自”原链接，整理版由 `prepare_organized.py` 展开引用。

## 获取直接关联

1. 从报告的 `references[].target_id` 提取并去重目标 ID，优先复用本轮已取得的完整笔记。
2. 对尚未取得的目标使用 `memo_batch_get(ids)` 补取，重试上限沿用 [flomo_api.md](flomo_api.md)。这些目标可以不在导出清单或当前日期内。
3. 将取得的目标对象保存为临时 JSON 数组（或 `{"memos": [...]}`），传给 `prepare_organized.py --related`。全部不可用时传入空数组；截断对象可保留，脚本会记录未展开原因。

导出清单 `ids.json` 保持不变。关联目标仅作为当前笔记的上下文，不新增独立条目、不计入导出数量，也不因补取而下载它的音频。只获取直接目标；目标正文内的其他关联继续保留链接。

## 整理版中的表示

脚本识别独立成行的 `关联自：<flomo 笔记链接>`，兼容半角冒号、Markdown 链接、尖括号链接和 `memo\_id` 转义。普通网址、来源元信息，以及代码块或已有引用中的链接保持原样。

有完整文字正文时，原关联行替换为：

```markdown
关联笔记：[查看原文](https://v.flomoapp.com/mine/?memo_id=目标ID)

> 被关联笔记的原文第一段。
>
> 被关联笔记的原文第二段。
```

引用保留目标正文的段落、列表、标题、已有引用及转义；只沿用原始版去掉开头自动标签行的处理。引用属于原文材料，不进行语音润色、摘要或观点整理。

目标缺失、正文截断或没有可引用文字时，保留原关联行，并在报告的 `reference_results` 和交付说明中记录未展开原因。取得目标当前正文即可；不推测它在建立关联时的历史版本。

每次运行底稿脚本都会从原始版重建整理版，覆盖同名文件并清除完成标记。先准备关联引用，再整理语音正文。校验脚本通过引用校验值检查原文没有被改写，将引用还原为原关联行后核对文档结构。
