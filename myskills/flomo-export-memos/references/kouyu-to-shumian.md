# 口语转书面语（文本整理规则）

用于把「录音转文字」的 flomo 笔记正文整理为通顺的书面语。**仅适用于整理版（`<day>-整理版.md`）中本条语音笔记的正文**。原始版、纯文字正文和展开的关联原文引用保持逐字内容；即使关联笔记本身来自语音，其引用也保留原文。

**处理原则——忠于原文：**
这一步只做语言层面的清洁工作，不改变内容结构、不增删观点、不重新组织段落。把它想象成一个专业的速记员在做"逐字稿→整理稿"的转换：听懂说话人的意思，但只清除语言噪音，不添加自己的理解。

开始整理前，读取 [个人术语表](personal-terms.md)，先按下文“语音识别纠正”规则核对名词，再清理语句。

**需要清理的内容：**

1. **语气词和填充词**
   删除不承载信息的语气词：是吧、对吧、是不是、好、好吧、啊、嗯、呢、吧、哈、嘿、哎、唉、那个、这个、就是说、怎么说呢、你知道吗……

   注意：当这些词承载实际语义时要保留。比如"好，我们开始"中的"好"是转折信号，应保留。

2. **口语重复**
   将连续重复的词语合并为一个：
   - "一个一个一个一个" → "一个"
   - "那那那那" → "那"
   - "去去去" → "去"
   - "和和和" → "和"
   - 以及结巴式的重复如"英英国那些英英国那些" → "英国那些"

3. **时间戳**
   删除正文内所有录音时间标记，如 `00:07`、`01:38`、`12:30` 等格式的时间戳。（注意：只删正文里的时间戳，每条笔记的 `### HH:MM` 小标题是结构信息，必须保留。）

4. **冗余表达精简**
   将散乱的口语表述整理为通顺的书面语：
   - 保持说话人的原意和逻辑顺序
   - 不要合并段落、不要调整段落顺序
   - 不要增加总结性文字或过渡句
   - 只让句子读起来更流畅

5. **语音识别纠正**
   原始版正文是录音经过语音识别（ASR）得到的，语音识别引擎会把一些词听错——最常见的是同音字/近音字替换（如人名、专业术语、地名等）。在整理过程中，需要根据上下文语义识别出这些识别错误并纠正。

   **判断方法：**
   - 某个词放在句中语义不通或很突兀，但换成一个发音相近的词就合理了——这大概率是语音识别错误
   - 尤其关注人名、机构名、专业术语、成语、固定搭配，这些是语音识别最容易出错的地方
   - 同一个名称在文中出现多次但写法不一致，通常说明部分出现是识别错误

   **纠正原则：**
   - 优先结合语境核对术语表中的已知误写；新的近音写法也可参考正确名称判断，避免脱离语境批量替换
   - 只纠正有较高把握的错误；疑似识别错误但拿不准的名词保留原文，并记入本轮清单
   - 已经正确的专业表达保持原样；词表外的明显错误仍可纠正，不能仅因某个名词不在表中就改写或列为拿不准
   - 纠正后要确保在上下文中语义通顺
   - 新词和错误写法经用户确认后再补入术语表，临时推测只用于本轮判断

## 独立的术语校对清单

本轮有语音笔记时，在全部日期整理完成后，在输出目录新建 `术语校对清单-<YYYYMMDD-HHMMSS>.md`，时间戳使用本轮生成清单的时间。每轮汇总一份，使用未占用的文件名，保留往轮清单。

- **已经修改的：**逐项列出本轮实际完成的 ASR 纠正，格式为“修改前 - 修改后”；同一对应关系去重。只记录最终整理版确实做出的纠正，不列普通口语清理，也不直接抄写术语表。
- **拿不准的：**逐项列出本轮发现的、尚未纠正的疑似误识别名词，保留原文写法并去重，不把推测的正确写法当作结论。
- 两个栏目均保留；没有条目时写“无”。交付前对照最终整理版核对清单，确保实际纠正和待确认名词无遗漏，并向用户提供该文件路径。

以下仅示例格式，实际条目以本轮处理结果为准：

```markdown
# 术语校对清单

## 已经修改的

- Pass You - Paseo
- Motica - Multica
- 莫问东西 - 墨问西东

## 拿不准的

无
```
