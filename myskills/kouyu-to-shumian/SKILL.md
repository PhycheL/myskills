# 口语转书面语

**处理原则——忠于原文：**这一步只做语言层面的工作，不改变内容结构、不增删观点、不重新组织段落。把它想象成一个专业的速记员在做“逐字稿→整理稿”的转换：听懂说话人的意思，清除语言噪音，把口语改成书面语，不添加自己的理解。

## 1. 确定范围和产物

输入是转写文本文件（一轮可以有多个）或粘贴的文字。先确定以下三项；用户或调用方已指定的，以指定为准。

- **整理范围**：默认是全部转写正文。范围外的内容逐字保留。
- **结构信息**：Markdown 标题（包括 `### HH:MM` 这样的时间小标题）、说话人标签、元信息、媒体标记、链接和分隔符，除第 3 步删除的内容外逐字保留。
- **整理版**：原文件保持不变，在同目录新建 `<原文件名去掉扩展名>-整理版.md`；同名文件已存在时，先问用户覆盖还是换名。调用方已准备底稿时，直接在底稿上修改，核对时以修改前的底稿为原文。粘贴的文字在回复中给出整理结果和清单。

## 2. 纠正语音识别错误

语音识别（ASR）引擎会把一些词听错，最常见的是同音字、近音字替换（如人名、专业术语、地名等）。先读取[个人术语表](references/personal-terms.md)，根据上下文语义核对名词，再清理语句；同时记录实际纠正和拿不准的名词，供第 4 步使用。

**判断方法：**

- 某个词放在句中语义不通或很突兀，但换成一个发音相近的词就合理了——这大概率是语音识别错误
- 尤其关注人名、机构名、专业术语、成语、固定搭配，这些是语音识别最容易出错的地方
- 同一个名称在文中出现多次但写法不一致，通常说明部分出现是识别错误

**纠正原则：**

- 优先结合语境核对术语表中的已知误写；新的近音写法也可参考正确名称判断，避免脱离语境批量替换
- 只纠正有较高把握的错误；疑似识别错误但拿不准的名词保留原文，并记入本轮清单
- 已经正确的专业表达保持原样；词表外的明显错误仍可纠正，不能仅因某个名词不在表中就改写或列为拿不准
- 纠正后要确保在上下文中语义通顺
- 新词和错误写法经用户确认后再补入术语表，临时推测只用于本轮判断

## 3. 清理语言

长稿按段分批处理，逐批写入整理版，直到原文最后一段。

1. **语气词和填充词**
   删除不承载信息的语气词：是吧、对吧、是不是、好、好吧、啊、嗯、呢、吧、哈、嘿、哎、唉、那个、这个、就是说、怎么说呢、你知道吗……

   注意：当这些词承载实际语义时要保留。比如“好，我们开始”中的“好”是转折信号，应保留。

   整段只含语气词时删除该段；说话人标签因此没有内容时一并删除。

2. **口语重复**
   将连续重复的词语合并为一个：
   - “一个一个一个一个” → “一个”
   - “那那那那” → “那”
   - “去去去” → “去”
   - “和和和” → “和”
   - 以及结巴式的重复如“英英国那些英英国那些” → “英国那些”

3. **时间戳**
   删除正文内所有录音时间标记，如 `00:07`、`01:38`、`12:30`、`00:07-00:12` 等格式的时间戳，包括说话人标签后面的时间戳。说话内容里的钟点（如“下午 12:30 开会”）属于内容，保留。

4. **冗余表达精简**
   将散乱的口语表述整理为通顺的书面语：
   - 保持说话人的原意和逻辑顺序
   - 不要合并段落、不要调整段落顺序
   - 不要增加总结性文字或过渡句
   - 让句子读起来更流畅

5. **用词书面化**
   把口语用词换成平实的书面语：
   - “最近” → “近期”
   - “总觉得” → “总体上感觉”
   - “一起完成” → “协同完成”
   - “还适不适合” → “还是否适合”
   - “写得挺好的” → “写得很好”

   边界：
   - 意思和语气强度不变：“不太行”写成“不太可行”，不写成“不可行”
   - 说话人的关键词和有力的判断保留（如“鸡肋”）；术语和专有名词以第 2 步的结果为准
   - 书面语不是把话拉长：短词够用就不换长词，少用“被”字句

## 4. 生成术语校对清单

全部文件整理完成后，在整理版所在目录（跨目录时放在共同上级目录）新建 `术语校对清单-<YYYYMMDD-HHMMSS>.md`，时间戳使用本轮生成清单的时间。每轮汇总一份，使用未占用的文件名，保留往轮清单。

- **已经修改的：**逐项列出本轮实际完成的 ASR 纠正，格式为“修改前 - 修改后”；同一对应关系去重。只记录最终整理版确实做出的纠正，不列普通口语清理和用词调整，也不直接抄写术语表。
- **拿不准的：**逐项列出本轮在整理范围内发现的、尚未纠正的疑似误识别名词，保留原文写法并去重，不把推测的正确写法当作结论。
- 两个栏目均保留；没有条目时写“无”。

以下仅示例格式，实际条目以本轮处理结果为准：

```markdown
# 术语校对清单

## 已经修改的

- Pass You - Paseo
- 莫问东西 - 墨问西东
- 单位已经在场 - 单位遗产在场

## 拿不准的

无
```

## 5. 核对和交付

对照原文逐段核对，全部满足才算完成：

- 整理版覆盖到原文最后一段，段落与原文一一对应、顺序不变（第 3 步删除的纯语气词段落除外），没有新增的总结、过渡或观点。
- 范围外内容和结构信息与原文逐字一致（第 3 步删除的除外），原文件未被改动。
- 正文没有残留录音时间戳。
- 口语用词已换成书面语，意思和语气强度与原文一致。
- 清单与最终整理版一致，实际纠正和待确认名词无遗漏。

在回复中给出整理版和清单的路径，并列出“拿不准的”名词请用户确认；确认结果按第 2 步的原则补入术语表。
