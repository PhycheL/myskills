# 主结构与结构纪律

## 一、怎么选主结构：先问"读者最后带走的是什么"

| 读者带走的是…… | 主结构 |
|---|---|
| 一个层层推出来的判断 | ① 递进式 |
| 做好某件事的几个要点 | ② 总分总 |
| 一次失误的教训 | ③ 问题—原因—对策 |
| 一个随时间改变了的看法 | ④ 时间对比式 |
| 对一个误解的纠正 | ⑤ 破立式 |
| 一个问题和它的解法（产品、技术、方案） | ⑥ 场景—问题—方案式（6a～6d，见 scene-problem-solution.md） |

- **结构由中心论点决定，素材只是论据。** 文章里出现了产品，不代表这就是产品文。比如《有关 ETL 的思考》的中心论点是"ETL 不是必需的"，属于⑤破立式，文中的产品对比只是论据。
- **同一份素材可以用不同结构来写。** 比如《我对微服务的理解》：中心论点是"别把微服务只理解成架构"，就用⑤；中心论点是"微服务解决什么问题、怎么解决"，就用 6c。拿不准时把两个候选都列出来，让作者选。
- 允许嵌套，比如在 6b 的判断部分里，用④的方式讲"这个方案一年前不成立，现在成立了"。

## 二、①～⑤

### ① 递进式（层层深入）
- **适用**：观点文、趋势判断、"我怎么看 X"
- **形式**：现象 → 本质判断 → 推论 → 再往上一层
- **要求**：每一层都回答上一层引出的问题；相邻两层之间能用"所以""那么""再往前一步"连起来
- **作者的例子**：《AI 发展现状及其影响》：程序员的本质是在两个世界之间做翻译 → 所以程序员不会被取代 → 被取代的是只会写重复代码的人

### ② 总分总（并列式）
- **适用**："X 应该具备哪几个特点""做好 X 的几个关键"
- **形式**：中心论点 → 2～4 个并列的分论点 → 回到中心论点
- **要求**：分论点按同一个维度划分，互不重叠，不漏关键项；每个分论点都直接支撑中心论点
- **作者的例子**：《演进式方案》：好方案应该是演进式方案 → 能落地、能处理错误、能演进 → 每一点都讲"背后的世界观"

### ③ 问题—原因—对策
- **适用**：复盘、事故分析、项目反思
- **形式**：界定问题 → 分类找原因（流程、管理、人、技术）→ 找到根因 → 对策（落到流程或机制上）
- **要求**：每条对策都对应一个根因
- **作者的例子**：《十三五项目问题的反思》：硬件问题 → 原因分类 → 根因在签合同这个环节 → 修改大合同的审核流程

### ④ 时间对比式（演进式）
- **适用**：判断随着技术或环境变化而改变的话题
- **形式**：过去的判断（以及它在当时为什么合理）→ 什么条件变了 → 现在的判断 → 接下来怎么做
- **要求**："变化的条件"必须写清楚，它是全文的转折点
- **作者的例子**：2025 年 5 月我会建议先用 LangGraph 搭；现在模型已经能按 Skill 完成任务，我建议直接用成熟的 Agent 加 Skill

### ⑤ 破立式
- **适用**：纠正一个普遍的误解
- **形式**：常见理解 → 为什么不对或不够 → 新理解（本质判断）→ 按新理解应该怎么做
- **要求**："破"的部分要有论据支撑
- **作者的例子**：《有关 ETL 的思考》：都在纠结 ETL → ETL 的本质是低代码，做不好就是鸡肋 → 代码提交 + 工作流调度更好用

## 三、开头和结尾
- **开头（2～4 句）**：一个具体的触发点（一次面试、一次讨论、一份材料、一个项目问题），然后给出中心论点或写作目的。观点多、篇幅长的文章，可以加一句路线说明（"我想从三个层面说"）。
- **结尾**：先回扣开头的中心论点，再从下面三种方式中选一种或组合：
  1. 回到行动："接下来需要做以下几件事：……"
  2. 提一个真问题，并给出初步答案
  3. 交代边界，加一句自嘲

## 四、结构纪律
- 全文只有一种主结构。某个部分内部可以嵌套另一种结构，最多嵌套两层。
- 一个部分只讲一件事，段首第一句就说出这部分的结论。
- 进入新部分时，用一句过渡说明它和上一部分的关系（因果、递进、并列、转折）。
- 和中心论点无关的内容，即使素材里有，也移出正文，列进结构方案的"移出主线"。
- 小标题连起来读就是全文提纲。小标题写成朴素的结论句（例："权限：给数字员工单独一套账号"），而不是话题词（例："权限问题"）。
- 篇幅向主线倾斜：最核心的那一层或那一点，篇幅最多。

## 五、思路检验
1. **连读论点链**：把各部分的一句话结论按顺序连起来，应该是一段通顺、完整的论证。读不通，先改结构。
2. **删除测试**：删掉任意一个部分，论证会断吗？不会断，说明这部分多余，或者放错了位置。
3. **换序测试**（递进式）：调换两层的顺序后应该读不通。如果还读得通，说明它们其实是并列关系，应该改成总分总。
4. **一句话复述**：读完以后，能用一句话复述中心论点吗？
