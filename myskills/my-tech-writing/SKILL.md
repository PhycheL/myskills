# 作者风格的技术文章写作

## 核心原则

1. **主线第一，一篇只说一件事。** 主线 = 中心论点 + 论点链（每个部分一句结论，按顺序连起来是一段完整的论证）。读者必须能看清主线。素材里有两个中心论点时，让作者选一个，另一个移出主线。要求冲突时按这个顺序取舍：主线 > 逻辑手法 > 语气 > 语言。
2. **有本质判断。** 每篇至少一句单独成段的本质判断（"X 本质上是 Y""关键是……"），后面的结论从它推出来。
3. **事实只来自作者。** 经历、人名、产品、日期、数据只用作者给的；缺的用【需作者补充：……】或【需作者确认：……】占位。
4. **观点只来自作者，推理可以补。** 判断只用作者表达过的；沿作者已有论点补出的推理和论据可以写进正文，每一处都在回复里列出，请作者确认。收尾句、总结句不算推理，不能补。作者原话里有力的句子原样保留；保留的是观点和力度，口语里顺口说出的绝对词（"唯一""必然"）和语病不在保留范围内。

## 产出文件

每一步的产出都写成 Markdown 文件，放在同一个输出目录里：

| 文件 | 内容 | 写于 |
|---|---|---|
| `01_结构方案.md` | 结构方案 | 第一步 |
| `02_正文.md` | 可以直接发表的正文，只含标题和正文 | 第二步 |

输出目录：作者指定了就用作者的；否则在素材文件同级新建一个以文章主题命名的文件夹；素材是直接贴在对话里的，就在当前工作目录下新建。每写完一个文件，在回复里给出它的路径。

## 分支

| 作者给的 | 走法 |
|---|---|
| 笔记、学习笔记、语音转写，或主题加观点 | 第一步 → 等确认 → 第二步 |
| 自己的初稿 | 同上；第一步从初稿里抽出主线，并加一项"结构问题" |
| 只要润色语言 | 读 `references/style.md` 和 `references/examples.md`，保持结构直接改，写进 `02_正文.md`；发现的结构问题在回复里列出 |

两种附加指令：

- **"直接写"**：不等确认，`01_结构方案.md` 只写 3～5 行（中心论点、主结构、论点链），接着做第二步。素材里有两个中心论点时，也不能跳过，先停下请作者选。
- **指定了结构**（如"按 6b 写"）：`01_结构方案.md` 只写论点链和断点。

## 第一步：结构方案

读 `references/structures.md`；选了⑥或候选里有⑥，再读 `references/scene-problem-solution.md`。然后把下面各项写进 `01_结构方案.md`：

- **中心论点**：一句话。素材里出现两个中心论点（判断方法见 structures.md 的"一篇只说一件事"），把两个都写出来，推荐一个，让作者选；另一个整体列进"移出主线"，注明可以单独成篇
- **主结构**：①～⑥中的哪一种（⑥要写明 6a～6d），以及为什么。拿不准时列两个候选
- **论点链**：每个部分一句结论，相邻部分之间标关系词（所以 / 那么 / 另外 / 但是）
- **素材处理**：素材的每一段怎么处理：放进哪个部分、和哪段合并，或者删掉。重复的口语说法合并；删掉的列进"移出主线"
- **断点**：缺论据、缺答案的地方，用占位符标出
- **检验**：逐项做 structures.md 的"思路检验"（选⑥的再加问题测试和对应测试），写出每项结果
- **结构问题**（仅初稿）：对照核心原则和 structures.md 的"结构纪律"，逐条列出原稿的问题

完成标准：`01_结构方案.md` 已写入；只有一个中心论点（或已列出两个请作者选）；素材的每一段都有处理结果；论点链连读通顺；每项检验都写了结果。然后停下，等作者确认。作者对结构提了修改，先改好 `01_结构方案.md`，再进入第二步。

作者说某处"绕"或要求"压缩"时："绕"指逻辑绕，要理顺推理的顺序、合并重复的论述；压缩删的是重复和多余的论述。两者都不是把长句拆短、删掉连接词。

## 第二步：正文

读 `references/style.md` 和 `references/examples.md`，按确认后的结构把正文写进 `02_正文.md`。结构方案是给作者看的骨架，里面的标签和编号（第一层、第二层、部分 X）不进正文，层次靠内容自己显出来。语音转写造成的错别字、"的地得"误用和指代不清一并改掉。

写完后在回复里给出**整理说明**，让作者发表前能逐条核对 AI 加了什么、改了什么：

- 每一处补出的推理或论据：引一句正文原文，说明补了什么，请作者确认
- 改初稿时：主要改动和理由

两项都没有内容时，说一句"没有补充推理"即可。

完成标准（逐项核对后再交付）：

- `02_正文.md` 已写入，只含标题和正文
- 第一步的检验在正文上重做一遍，仍然全部通过
- 逐段删除测试：删掉这一段，作者的观点少了什么？什么都没少的段落删掉
- 正文里每一处补出的推理，都在整理说明里列出
- 节奏：连续三句长度相近、结构相同的，已改写其中一句（style.md 四）
- 绝对词：全文搜过"唯一""必然""一定""完全""所有"，有反例的已降级（style.md 三）
- 压缩过的句子仍然有时间、主体、范围，没有语病（style.md 五）
- style.md 里的简洁检查、次数上限和护栏逐个核对过
