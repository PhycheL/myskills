还有一个问题是，现在 skill 有的时候并不是那么听话，它只是指示性的。在 skill 和 langgraph 这样的选型中间，我选 skill 是因为 AI native 和 workflow 的区别。第一，我现在选 skill 是为了未来一到两年大模型的一个演进。现在 skill 表现不好，很有可能是大模型能力不足，指令追随能力不足。随着大模型的发展，它对于 skill 会做得越来越好。langgraph 这一块，更多的问题在于它把所有的流程都规定死了，无法发挥大模型的一个优势，不能让大模型自己去寻找一些路径。有些事情不是一个固定的流程，或者说固定的流程不可能解决大量的问题。这种情况下，skill 这种指示性的可能更好一些。第三点，这个东西到底怎么样，其实还是要去试。比如我们做了一些很多数字员工，一开始肯定是用 skill 加 hook 去做。如果测的不好，很可能就退回到 langgraph，这也是有可能的。但我觉得肯定首先要上 skill。
